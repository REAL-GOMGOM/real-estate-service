# 공통 메뉴·홈 관심 지역 — 2026-09-06

남은 개선 항목 중 첫 번째인 탐색 일관성과 홈 관심 지역을 처리한다. 장기간 거래 원장·운영 자동화·광고·분석 지표 개선은 다음 작업으로 분리한다.

## 변경 범위

- 홈과 공통 헤더 페이지가 하나의 메뉴 정의를 사용한다. PC는 클릭 드롭다운, 모바일은 같은 목적지의 아코디언을 제공한다. 하단 더보기의 중복 링크 이름도 동일한 정의를 따른다.
- `시장 한눈에`를 시장 동향에 포함하고 기존 더보기 순서를 유지한다. 칼럼 비공개 정책은 그대로이며 글·피드 원본을 삭제하거나 복원하지 않는다.
- 홈 소개 문구 `부동산의 모든 답을, 한 곳에 압축하다`와 주요 콘텐츠는 유지한다.
- 홈 최근 실거래에서 지원 지역 248개 중 하나를 시도·권역 → 시군구 순서로 직접 선택할 수 있다. 현재 조회 가능한 canonical 지역 목록 기준이며 모든 행정구역을 새로 지원한다는 뜻은 아니다.
- 확정한 지역명 하나만 `naezip.home-district.v1`에 저장한다. 위치 권한·좌표·선택 이력은 수집하지 않는다. 조회 API에는 선택한 지역명이 포함된다. 개인정보처리방침에 이 동작과 삭제 방법을 안내한다.
- 저장 차단 시 현재 화면의 조회는 계속되고 저장 실패를 안내한다. SSR에서 브라우저 저장소를 읽지 않고, 복원 전에 기본 지역 API를 중복 호출하지 않는다. 빠른 변경이나 다른 탭의 저장 변경에서도 이전 응답이 새 지역 결과를 덮어쓰지 않는다.
- 기존 2개월·최대 60개 단지 조회 후 최근 거래 4개 표시 범위는 유지한다. 전체 원장의 최신 거래 순위를 새로 집계한 기능은 아니다. 단지·동·계약 식별자를 보존하여 정확한 거래 상세로 연결한다.
- 홈뿐 아니라 실거래 상세의 권역 판별·지역 변경 모달도 같은 지원 지역 목록을 쓴다. 홍천군 같은 군 지역의 링크가 서울 권역으로 잘못 진입하지 않는다.
- 기존 집계용 curated 지역 목록·API·공개 스냅샷 계약은 바꾸지 않았다. 통계에 없는 지원 지역은 숫자를 임의로 0으로 만들지 않고 `·`로 표시하며 선택 가능하게 유지한다.
