# 실거래 정확성 개선 — 2026-09-06

## 이번 반영 범위

1. **검색·공유의 단지 식별 보존**
   - 전세·월세·분양권도 검증된 단지 ID로 서버에서 먼저 필터링한다.
   - 구별 상위 60개 목록 밖의 단지가 `0건`으로 사라지지 않는다.
   - 기존 이름 기반 URL은 동 정보까지 전달하며, 새 공유 URL에는 가능한 경우 단지 ID·거래 유형·계약 식별자를 보존한다.
   - 단지 조회는 계약 내역을 최근 10개로 자르지 않아 이전 공유 계약도 확인할 수 있다.
   - 기준 데이터 장애(503)와 확인된 단지 없음(404)을 구분한다.
   - URL의 기간·거래 유형이 바뀌면 새 요청에 해당하는 응답을 기다린 후 공유 계약을 연다. 이전 응답으로 새 링크를 열지 않는다.

2. **가격 비교 기준 통일**
   - 최신 표시 거래의 유사 면적(기존 기준 ±6㎡)과 조회 기간으로 카드·상세·공유 비교를 통일한다.
   - 과거 계약을 공유할 때 그 계약보다 미래의 거래를 비교에 사용하지 않는다.
   - 비교 부족·동가·하락·기간 최고가 경신을 구분한다. 거래 1건을 신고가로 간주하지 않는다.
   - 같은 날짜의 선후관계나 서로 다른 직전 가격은 임의로 추정하지 않는다.
   - 월 단위만 알려진 기록이 대상 계약보다 미래일 수 있으면 비교에서 제외한다.
   - 상세 표의 비율도 계약 당시 유사 면적 기준이며, 차트에 다른 면적 가격을 섞지 않는다.
   - 카드의 거래 수 설명에는 실제 조회 기간을 표시한다.

## 검증

  - 강남구 일원동 `가람` 전세: 2건(9억, 8.8억) 표시.
  - `잠실엘스` 85㎡: 34.1억과 종전 33.5억 비교. 60㎡ 최고 30.05억을 기준으로 사용하지 않음.
