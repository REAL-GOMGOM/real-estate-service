## 변경 범위

- 매매·전월세·분양권 API의 `total`을 검색 필터 적용 후, 그룹 제한·최근 기록 축약 전에 계산한다. 같은 동의 타 단지 35건과 대상 단지 2건이 있으면 검색 합계는 2건이며, 전체 합계는 `limit=1`이어도 37건이다.
- 실거래 화면의 방문 날짜를 제거하고 성공한 응답의 스냅샷 기준 시각을 한국시간으로 표시한다. 일반 집계의 `updatedAt`은 수집 시각이 아니므로 별도로 ‘집계 생성’이라고 표시한다. 시각 누락·잘못된 값·조회 실패를 오늘 날짜로 대체하지 않는다.
- 데이터·기준 시각·오류/로딩 상태를 같은 조회 키로 복원한다. 다른 요청의 실패/취소 뒤 이전 조건으로 돌아와도 빈 데이터나 무한 로딩에 오래된 날짜를 붙이지 않는다. 지연된 응답은 현재 조회를 덮어쓰지 않는다.
- 메인 빈 제보 영역은 간결하게 줄이고 ‘미확인 정보·진위 미보증·공식 통계 미반영’ 안내와 제보 버튼은 유지한다. 이용 안내는 펼쳐 확인할 수 있다. 제보 폼과 검수·동의 절차는 변경하지 않는다.
- 공개 제보에는 서버가 선택·검증한 단지 ID와 거래 유형을 보존하는 공식 실거래 비교 링크를 추가한다. 미확인 제보 가격이나 날짜를 공식 계약 식별자로 만들지 않는다.
- 최근 거래 행은 단지·동·거래 식별자를 보존한 링크로 연결한다. 저장·최근 단지는 검색 바로 아래에 배치하며, 저장 내역이 없는 사용자에게 빈 카드를 만들지 않는다.
- 기존 메인 소개 문구, 가격 제보의 평·억원 단위, 익명·현장소식 옵션을 유지한다.
